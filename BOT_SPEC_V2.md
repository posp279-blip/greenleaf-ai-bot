# Greenleaf AI Bot v2 — утверждённая спецификация реализации

## 1. Статус документа

Этот файл — единый источник истины для реализации новой версии Telegram-бота Greenleaf в ветке `feature/friendly-scenario-v2`.

При противоречиях между прежними документами действуют следующие приоритеты:

1. **Дружеский сценарий ИИ-бота Greenleaf v2** — источник истины для пользовательского диалога, текстов, порядка блоков и ожидания ответа.
2. **Техническая часть ИИ-бота Greenleaf с партнёрским режимом** — источник истины для архитектуры, базы данных, Telegram- и web-админки, партнёров, рефералок, заявок, Proxy API, видео, калькулятора и аналитики.
3. Этот файл отменяет конфликтующие требования старой реализации.

## 2. Жёсткие продуктовые правила

- Бот общается на «ты» и ведёт живой диалог.
- После каждого вопроса бот обязан ждать ответ пользователя.
- Бот не отправляет подряд несколько следующих сценарных блоков.
